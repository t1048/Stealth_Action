# Stealth_Action (Stealth Rogue)
ローグライトな見下ろし型ステルスアクションゲーム。
プロシージャル生成されるマップを探索し、敵の監視を潜り抜け、目的を達成せよ。

## 🎮 公開ページ  
ゲームはここからブラウザで遊べます： 

[https://t1048.github.io/Stealth_Action](https://t1048.github.io/Stealth_Action)

## 🕹️ 操作方法

| キー | 動作 |
| --- | --- |
| **W / A / S / D** | 移動 |
| **Space** | アイテム使用 |
| **Q** | アイテムを捨てる |
| **1 - 4** | アイテムスロット切り替え |
| **左クリック** | 射撃 |
| **Enter** | ゲーム開始 / リスタート |

## ✨ 特徴

*   **緊張感のあるステルス体験**: 敵の視界や監視カメラを避けながら進む緊張感。足音や物音で敵が警戒モードに移行します。
*   **プロシージャル生成マップ**: プレイするたびに変化するマップレイアウト。「研究所」「森林遺跡」「深海」など多彩なテーマが存在。
*   **戦略的なアイテム**:
    *   **SPEED BOOST**: 一時的に移動速度が上昇。
    *   **WIDE SONAR**: 周囲の敵や地形を把握。
    *   **OPTICAL CLOAK**: 一時的に透明になり、敵の視界から消える。
    *   **KEYCARD**: セキュリティドアを解錠するために必要。
*   **賢い敵AI**: プレイヤーを見つけると追跡し、見失うと周辺を捜索します。壁を回避して追いかけてくる経路探索AIを搭載。
