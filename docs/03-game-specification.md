# 03 ゲーム仕様書

## 1. ゲーム概要

プレイヤーは見下ろし視点でマップを移動し、敵の視界と監視カメラを避けながらゴール（青いタイル）に到達する。ゴール到達でレベルクリア。敵に接触するとゲームオーバーとなり、レベル1から再開する。

---

## 2. 操作方法

| 入力 | 動作 | 実装 |
|---|---|---|
| W / A / S / D | 移動 | player.js `updatePlayer()` |
| 矢印キー | 移動（WASD と同等） | 同上 |
| Space | 選択中アイテムを使用 | player.js `useItem()` |
| Q | 選択中アイテムを廃棄 | player.js `dropItem()` |
| 1 - 4 | アイテムスロット切替 | player.js `selectItemBySlot()` |
| マウス移動 | 照準方向（プレイヤー角度） | game.js mousemove |
| 左クリック | スタンガン射撃 | player.js `fireStunGun()` |
| マウスホイール | アイテムスロット切替 | game.js wheel |
| Enter | ゲーム開始 / リスタート | game.js keydown |
| 音量スライダー | BGM/SE 音量（0-100%） | audio.js `setVolume()` |

---

## 3. ゲームルール

### 3.1 勝利条件

- プレイヤーがゴールタイル（`goal`）の矩形内に入るとレベルクリア
- `levelComplete()` により `level` がインクリメントされ、1秒後に次レベルが開始される

### 3.2 敗北条件

- STUNNED 以外の敵に接触（半径同士の距離判定）でゲームオーバー
- ゲームオーバー後 Enter で `initGame()` が呼ばれ、レベル1から再開

### 3.3 レベル間の引き継ぎ

| 項目 | 引き継ぎ |
|---|---|
| インベントリ | あり |
| キーカード（hasKeycard） | なし（レベル開始時にリセット） |
| スタン弾（stunAmmo） | なし（毎レベル3発にリセット） |
| レベル番号 | クリア時に +1 |

## 4. ゲーム状態

| 状態 | 説明 | 描画 |
|---|---|---|
| `START` | タイトル画面 | "STEALTH ROGUE" / "Press ENTER to Start" |
| `PLAYING` | プレイ中 | 通常描画 |
| `GOAL` | レベルクリア演出 | "LEVEL CLEAR!" |
| `GAMEOVER` | ゲームオーバー | "GAME OVER" / "Press ENTER to Retry" |

## 5. レベル進行

### 5.1 マップサイズ

| 条件 | COLS | ROWS |
|---|---|---|
| 通常レイアウト | `min(64, 20 + (level-1)*4)` | `min(52, 16 + (level-1)*3)` |
| security / upload | 44 | 26 |

偶数に丸められる（`Math.floor(n/2)*2`）。

### 5.2 テーマ

5種のテーマがレベル番号で循環する:

```
THEMES[(level - 1) % 5]
```

| # | 名称 |
|---|---|
| 1 | LABORATORY |
| 2 | FOREST RUINS |
| 3 | RED FORTRESS |
| 4 | DEEP OCEAN |
| 5 | GOLDEN VAULT |

### 5.3 特殊レイアウト出現

| レベル | イベント |
|---|---|
| 1-3 | cave / maze のみ |
| 4+ | `security` レイアウト出現（キーカード + セキュリティドア） |
| 6+ | `upload` レイアウト出現（アップロード端末 + 金庫ドア） |

### 5.4 ナビゲーション支援

- レベル開始から **45秒**（`NAV_ANNOUNCE_SECONDS * FPS`）経過後:
  - ナビメッセージがタイプライター表示される
  - ゴール方向を示す矢印（`navActive`）がプレイヤー周囲に表示される

## 6. アイテム仕様

### 6.1 一般アイテム

| ID | 定数名 | 名称 | 効果 | 持続（フレーム） | 消費 |
|---|---|---|---|---|---|
| 1 | ITEM_SPEED | SPEED BOOST | 移動速度 1.8倍 | 300 | 使用時に消費 |
| 2 | ITEM_VISION | WIDE SONAR | 視界半径 400px、Fog 解除 | 600 | 使用時に消費 |
| 3 | ITEM_CLOAK | OPTICAL CLOAK | 敵・カメラから不可視、速度 0.6倍 | 300 | 使用時に消費 |

- インベントリ上限: **8個**
- スロット表示: 種類ごとにユニーク表示（最大4スロット、1-4キーで選択）
- スロット優先順: CLOAK → SPEED → VISION

### 6.2 キーカード

| ID | 定数名 | 名称 | 効果 |
|---|---|---|---|
| 4 | ITEM_KEYCARD | KEYCARD | セキュリティドア解錠用 |

- 拾得時に `player.hasKeycard = true`（インベントリには入らない）
- security レイアウトの左施設に固定配置
- ドア近傍（距離 < TILE_SIZE * 0.8）で自動解錠

### 6.3 アイテム配置

- 基本: 2〜3個 + `floor(level/3)` 個
- 種類: SPEED / VISION / CLOAK からランダム（type 1-3）
- security レイアウト: キーカードを追加配置

## 7. スタンガン

| 項目 | 値 |
|---|---|
| 初期弾数 | 3（レベル開始ごとにリセット） |
| 弾速 | 14 px/frame |
| 寿命 | 60 フレーム |
| 命中判定半径 | enemy.radius + 25 |

**敵への効果:**
- 状態を `STUNNED` に変更
- `waitTimer = 300`（約5秒）

**カメラへの効果:**
- 状態を `DISABLED` に変更
- `disableTimer = 450`（約7.5秒）

弾は壁（`isWall`）に当たると消滅する。

## 8. Fog of War（視界）

| 条件 | 視界 |
|---|---|
| 通常 | プレイヤー中心、半径 **180px** の円形視界。それ以外は黒マスク |
| WIDE SONAR 発動中 | マスク解除、全体に薄緑オーバーレイ |
| 敵・カメラ視界 | 常時表示（Fog の外でも扇形が見える） |

## 9. 特殊オブジェクト

### 9.1 セキュリティドア（security レイアウト）

- 左右2施設を隔てる中央ドア
- キーカード所持 + 近接で解錠
- 未所持で近接: "ACCESS DENIED" 通知

### 9.2 アップロード端末（upload レイアウト）

- 端末エリア内に滞在するとアップロード進行
- 必要時間: **5秒**（`UPLOAD_REQUIRED_TIME = FPS * 5`）
- エリア外に出ると進捗が **2/frame** で減少
- 完了後: 金庫ドアが自動解錠（"UPLINK DOOR UNLOCKED" 通知。プレイヤー近接は不要）
- 未完了で近接: "UPLOAD REQUIRED" 通知

### 9.3 監視カメラ

- 壁際に配置、スイング監視
- 視界: 距離 130px、死角 40px、角度 π/6
- 検知時: 最寄りの敵を CHASE 状態にし、"SECURITY ALERT!" 通知

---

## 10. 敵仕様

| 項目 | 値 |
|---|---|
| 半径 | 12 px |
| 速度 | `(0.9 + level * 0.09) * 0.9` |
| 視界距離 | 160 px |
| 視界角度 | π/4（45°） |
| 追跡速度倍率 | 1.5倍 |

**状態:**
- **PATROL:** ウェイポイント巡回
- **CHASE:** プレイヤー追跡（A* 経路探索）
- **ALERT:** 原地で旋回（waitTimer 90f 後 PATROL 復帰）
- **STUNNED:** 停止（waitTimer 300f 後 ALERT へ）

**検知方式:** 扇形視界 + 壁遮蔽判定（`lineIntersectsWall`）のみ。
