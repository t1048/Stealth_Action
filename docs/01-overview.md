# 01 概要設計書

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| 正式タイトル | Stealth Rogue: Blind Spot |
| ジャンル | ローグライト × 見下ろし型ステルスアクション |
| プラットフォーム | Web ブラウザ（デスクトップ想定） |
| 公開先 | [GitHub Pages](https://t1048.github.io/Stealth_Action) |
| ライセンス | MIT |

プレイヤーはプロシージャル生成されたマップを探索し、敵の視界と監視カメラを避けながらゴールを目指す。レベルクリア後は次レベルへ進行し、難易度が段階的に上昇する。ゲームオーバー時はレベル1から再開する。

---

## 2. 目的・スコープ

### 2.1 目的

- 視界ベースのステルス体験を、外部ライブラリなしの軽量 Web ゲームとして提供する
- プロシージャル生成により、プレイごとに異なるマップレイアウトを実現する
- レベル進行に伴う難易度上昇と特殊レイアウト（セキュリティ施設・アップロード金庫）でゲーム性を深める

### 2.2 スコープ内

- 単一 HTML ページによるゲーム実行
- キーボード・マウス操作
- プロシージャルマップ生成（4種レイアウト）
- 敵 AI（巡回・追跡・警戒・スタン）および監視カメラ
- アイテム・スタンガン・Fog of War
- Web Audio API による BGM / SE

### 2.3 スコープ外

- セーブ / ロード機能
- マルチプレイヤー
- モバイルタッチ操作
- ビルドツール・npm 依存
- 自動テスト

---

## 3. 技術スタック

| カテゴリ | 技術 |
|---|---|
| マークアップ | HTML5 |
| スタイル | CSS3 |
| ロジック | Vanilla JavaScript（ES5/ES6 混在） |
| 描画 | HTML5 Canvas 2D（800×600 px） |
| 音声 | Web Audio API（Oscillator によるプロシージャル生成） |
| 外部依存 | **なし** |
| ビルド | **不要**（静的ファイルをそのまま配信） |

## 4. ディレクトリ構成

```
Stealth_Action/
├── index.html              # エントリーポイント（HTML + スクリプト読み込み）
├── README.md               # プレイヤー向け説明
├── LICENSE                 # MIT ライセンス

├── js/
│   ├── state.js            # 定数・グローバル状態・ユーティリティ
│   ├── audio.js            # Web Audio API（BGM / SE）
│   ├── map.js              # プロシージャルマップ生成・地形判定
│   ├── pathfinding.js      # A* 経路探索
│   ├── enemies.js          # 敵・監視カメラ AI
│   ├── player.js           # プレイヤー操作・アイテム・HUD
│   ├── rendering.js        # Canvas 描画・パーティクル
│   └── game.js             # メインループ・衝突・イベント（最終読み込み）
└── docs/                   # 本設計書群
```

全12ソースファイル（HTML/CSS/JS）のフラット構成。`package.json` やビルド設定は存在しない。

## 5. 実行環境

### 5.1 起動方法

1. `index.html` をブラウザで直接開く
2. または GitHub Pages 等の静的ホスティングで配信

### 5.2 想定ブラウザ

- Web Audio API および Canvas 2D をサポートするモダンブラウザ
- 音声はユーザー操作（Enter キーでゲーム開始）後に `AudioContext` が初期化される

### 5.3 画面構成

- **Canvas:** 800×600 px（ゲーム描画領域）
- **HUD:** レベル、スタン弾、キーカード、インベントリ、音量スライダー
- **通知エリア:** 画面上部中央（2秒でフェードアウト）

---

## 6. 非機能要件・制約

| 項目 | 内容 |
|---|---|
| アーキテクチャ | グローバル状態パターン（ES Modules 未使用） |
| 状態管理 | `state.js` が単一の状態ハブ |
| フレームレート | 60 FPS 想定（`requestAnimationFrame`） |
| セーブ | なし（ゲームオーバーでレベル1リセット、レベル間はインベントリのみ引き継ぎ） |
| 入力 | キーボード + マウス（タッチ未対応） |
| 国際化 | なし（UI テキストは英語中心、一部日本語メッセージあり） |
| テスト | 自動テストなし |
